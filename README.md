# 🔍 Claritas Verify

Claritas Verify is a Background Verification (BGV) platform designed to simplify and streamline the employee verification process. It enables organizations to submit verification requests, securely manage candidate information, and track verification status through an easy-to-use web application.

## 🚀 Features

- Secure User Registration & Login
- Submit Background Verification Requests
- Track Verification Status
- Candidate Information Management
- Secure Data Storage
- Responsive User Interface
- Email Authentication
- Firebase Integration

## 📌 Project Overview

The objective of Claritas Verify is to reduce manual verification efforts by providing a centralized platform for managing background verification requests. The application focuses on improving data accuracy, process transparency, and user experience.
